# Project Notes

## GitScribe MCP

For any git-cloned project, GitScribe MCP (`gitscribe-mcp`) MUST be started, connected, and verified active BEFORE planning, implementation, or code changes begin. Confirm the MCP server is running and its tools are available in the current session, and use it to record work/logs and generate documentation.

If GitScribe is not configured, not installed, or not active, STOP before planning or implementation and ask the user to provide its MCP command/path or permission to configure it. Do not silently proceed without it. Checking config files (`opencode.jsonc`/`.mcp.json`), the GitScribe RAG index/database, and the session tool list is mandatory.
