Photo-based identificationThe photos show an ESP-32U-marked module on a 38-pin development board with micro-USB, EN/BOOT buttons and an IPEX/U.FL-style antenna socket. A USB-UART bridge and 3V3 regulator are visible, but their markings/current rating are unreadable. The full board SKU and header order are unverified; the GPIO drawing is a logical map, not a physical pin-location template. Confirm GPIO16/17, power and ground labels on your actual board before wiring. Never connect 5 V to ESP32 GPIO or 3V3.
Controller responsibilities

UNO R3: four buttons, TFT rendering, menus, expressions/animations and QR actions. ESP-32U board: Wi-Fi, HTTP/API, session state and QR data. Existing framed UART protocol is unchanged.

Power arrangement

Power the UNO and ESP-32U board through their own USB inputs. Share GND. Do not tie the USB 5 V rails or UNO 5 V to ESP32 GPIO/3V3.

Storage / antenna

LittleFS remains on ESP32 flash; no microSD. Connect a compatible 2.4 GHz antenna to the board’s IPEX/U.FL-style socket before enabling Wi-Fi.

      Wiring guide

        Start with the power source and ground, then connect the TFT and buttons.

        OPTION C · AUTOMATIC START · PHONE-BASED ADMIN

        Startup and classroom access

        1. When USB power is connected, the ESP32 boots, loads classroom records from microSD, and starts its local SNTCH Wi-Fi network.
        2. The TFT displays the controller QR, Wi-Fi name and manual connection address. It switches to a student join QR when exactly one activity is live.
        3. The teacher connects their phone and uses the app’s teacher sign-in and administration screens. Students use the student join flow.
        4. There are no user-facing panel buttons. The app is the menu; the board’s EN/BOOT controls are for recovery and programming, not normal classroom use.

        Access control: Keep the network protected and require the teacher PIN for teacher functions. Do not put the PIN in a QR code or display it on the TFT. The existing teacher app manages classroom records and sessions; changing Wi-Fi credentials or firmware settings from the phone would need additional app and firmware work.

        microSD connections

        Wire a separate SPI microSD module to the ESP32 header using the connections below, then insert a prepared FAT32 card. The classroom service will not start if it cannot mount the card. Options A and B use internal LittleFS.

        VERSION B · PHYSICAL PLACEMENT

        Exact breadboard holes

        Use just the half-size breadboard. Orient it so A–E is above the center gap and F–J below. Count columns from the left. Holes A–E in one numbered column are connected; F–J is a separate strip. On the same side of the gap, put the two switch contacts in different numbered columns.

        Button / boardGPIO jumperOpposite switch contactsGround jumper

        Common ground: ESP32 GND → half-size rail −2. The four switches connect to this same ground rail, not the positive rail.

        Check each power rail: + and − refer to the adjacent rail pair below row J. Count the 25 actual rail holes from the left, skipping the gaps between groups. They do not line up one-for-one with the lettered holes. For a measured midpoint split, bridge +9 → +17 and −9 → −17 as needed; never join + to −. Turn on “Show split rail bridges” below if yours needs them.

        Match the pins, not the drawing: The selector changes the connection table and the diagram. With power off, confirm each button fits without bending its pins and that the chosen holes are disconnected until pressed. If no layout fits, use a matching adapter or short leads to the listed holes.

        Find the correct contacts on a small button
        • Two-pin normally open button: use both pins in the two listed contact holes. Polarity does not matter.
        • Four-pin tactile button: use one leg from each internally connected pair. Check the mounted switch: none of the other legs may join the input and ground strips at rest. The input and return must show no continuity at rest and continuity only while pressed.

        The TFT signal jumpers run directly to the ESP32 header; don’t put them into a breadboard power rail.
